## 2. 项目1：供应链供应商预约管理系统

### 2.1 系统架构

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 供应商管理 │    │ 预约管理   │    │ 入园管理   │    │ 收台管理   │
│  Module   │    │  Module   │    │  Module   │    │  Module   │
└─────┬────┘    └─────┬────┘    └─────┬────┘    └─────┬────┘
      │               │               │               │
      └───────────────┼───────────────┼───────────────┘
                      │               │
              ┌───────▼───────┐ ┌─────▼──────┐
              │  Service Layer │ │ MQ Consumer │
              └───────┬───────┘ └─────┬──────┘
                      │               │
        ┌─────────────┼───────────────┤
        │             │               │
   ┌────▼────┐  ┌─────▼────┐  ┌──────▼─────┐
   │  MySQL   │  │  Redis   │  │  RabbitMQ  │
   │ 持久化存储 │  │ 缓存/锁  │  │ 异步/联动  │
   └─────────┘  └──────────┘  └────────────┘
```

### 2.2 核心流程

#### 预约→门禁→收台联动流程

```
供应商发起预约
      │
      ▼
 预约创建（Redis分布式锁 + 乐观锁）
      │
      ▼
 预约确认 → RabbitMQ [booking.linkage]
      │
      ├──→ 门禁系统：自动创建入园登记
      │
      └──→ 收台系统：自动创建收台记录
```

#### 资质过期预警流程

```
定时任务（每天08:00）
      │
      ▼
 扫描3天内即将过期的资质
      │
      ▼
 RabbitMQ [qualification.warning]
      │
      ▼
 预警消费者 → 通知供应商 + 标记预警状态
```

### 2.3 数据库ER图

```
supplier (1) ──── (N) supplier_qualification
    │
    └──── (N) booking_order (N) ──── (1) time_slot
                    │
                    ├── (1) park_entry
                    └── (1) receiving_record

cold_chain_vehicle (N) ──── (1) supplier
```

### 2.4 缓存设计

| 缓存Key | 数据 | TTL | 策略 |
|---------|------|-----|------|
| `supply:supplier:{id}` | 供应商信息 | 24h | 旁路缓存 |
| `supply:timeslot:{id}` | 时段信息 | 1h | 旁路缓存 |
| `supply:booking:lock:{timeSlotId}` | 预约分布式锁 | 30s | SET NX EX |
| `supply:rate:{ip}` | 限流令牌桶 | - | 令牌桶算法 |
| `supply:stats:daily:{date}` | 日统计数据 | 7d | 定时刷新 |

## 3. 项目2：企业RAG知识库问答系统

### 3.1 RAG架构

```
┌──────────────────────────────────────────────────┐
│                   用户提问                         │
└──────────────────────┬───────────────────────────┘
                       │
               ┌───────▼───────┐
               │   意图识别      │
               │ (关键词+LLM)   │
               └───────┬───────┘
                       │
               ┌───────▼───────┐
               │   向量检索      │
               │ (Embedding+   │
               │  余弦相似度)    │
               └───────┬───────┘
                       │
               ┌───────▼───────┐
               │  Prompt构造    │
               │ (System+Ctx+  │
               │  History)     │
               └───────┬───────┘
                       │
               ┌───────▼───────┐
               │  LLM生成回答   │
               │ (Ollama本地)  │
               └───────┬───────┘
                       │
               ┌───────▼───────┐
               │  记录+缓存     │
               └───────────────┘
```

### 3.2 文档处理流程

```
文档上传 → 解析(PDF/Word/TXT) → 分块(Chunk) → 向量化(Embedding) → 存储
                                                              │
                                            ┌─────────────────┤
                                            │                 │
                                      MySQL(chunk+向量)    Redis(缓存)
```

### 3.3 分块策略

| 策略 | 实现 | 适用场景 |
|------|------|----------|
| 固定大小分块 | 512 tokens，重叠64 tokens | 通用文档 |
| 语义分块 | 按章节/段落边界切分 | 结构化文档 |

## 4. 项目3：微服务权限中台

### 4.1 微服务架构

```
                    ┌─────────────┐
                    │    Nacos     │
                    │ (注册/配置)  │
                    └──────┬──────┘
                           │
┌──────────┐    ┌──────────▼──────────┐    ┌──────────┐
│  客户端   │───→│   API Gateway       │───→│ 业务系统A │
└──────────┘    │ (鉴权/限流/路由)     │    └──────────┘
                └──────────┬──────────┘
                           │
                ┌──────────▼──────────┐
                │   Auth System       │
                │ (认证/授权/用户管理)  │
                └──────────┬──────────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
         ┌────▼────┐ ┌────▼────┐ ┌────▼────┐
         │  MySQL  │ │  Redis  │ │Sentinel │
         │ 用户/角色│ │ 会话/锁 │ │ 限流/熔断│
         └─────────┘ └─────────┘ └─────────┘
```

### 4.2 RBAC权限模型

```
用户(User) ──M:N── 角色(Role) ──M:N── 菜单(Menu/Permission)
     │                                          │
     └── 数据权限(DataPermission) ──────────────┘
          ├── 全部数据
          ├── 本部门数据
          ├── 本部门及下级
          └── 自定义数据
```

### 4.3 SSO单点登录流程

```
系统A登录 → 生成Ticket → Redis存储 → 重定向到系统B
                                          │
系统B验证Ticket ← Redis查询 ← 携带Ticket ←┘
      │
      ▼
  生成系统B的Token → 登录成功
```

### 4.4 网关三层防护

```
请求 → BlackListFilter(IP黑名单) → AuthGlobalFilter(JWT鉴权) → Sentinel(限流熔断) → 后端服务
```
